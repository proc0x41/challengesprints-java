# Capturas reais da integração

Os quatro PNGs foram capturados em 03/11/2026 no frontend da Alpha4, consumindo
a API Spring Boot local em `http://localhost:8080/api`.

- `missoes-desktop.png`: listagem com dados persistidos.
- `detalhe-desktop.png`: rota dinâmica e formulário de evidência.
- `ranking-desktop.png`: temporada e pontuação calculadas no backend.
- `perfil-mobile.png`: perfil e acompanhamentos em viewport de 390 px.

Origem: `chellengesprints-alpha4/docs/screenshots`, outro projeto do mesmo
workspace. São evidências reais do ambiente de demonstração, sem alegação
de deploy público. Os pseudônimos de teste não são pessoas reais. O PDF
mostra a imagem móvel em faixas com pequena sobreposição para preservar linhas,
sem modificar o PNG original.
